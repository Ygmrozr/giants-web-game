# Beyond Giants Canvas Game

This project is a web-based game developed as a Computer Engineering graduation project.

The game is built using Node.js, Express, EJS and HTML5 Canvas.  
Users can create an account, log in and play the game.

## Features

- User registration and login
- Email verification
- Password reset system
- Secure password hashing (bcrypt)
- Canvas based game

## Technologies

- Node.js
- Express.js
- EJS
- MongoDB
- HTML5 Canvas
- JavaScript

## Installation

Clone the repository:

git clone https://github.com/Ygmrozr/giants-web-game.git

Go to the project folder:

cd giants-web-game

Install dependencies:

npm install

Run the project:

node server.js

Server runs at:

http://localhost:5000
